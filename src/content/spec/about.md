# 关于我

你好，我是 **StarryDawn** 👋

这里是我的个人小站，用来记录学习和生活里的一些东西 —— 课程笔记、读书心得、踩过的坑，还有一些零碎的感受。

「StarryDawn」这个名字，是希望即使在平凡的日子里，也能对星空保留一点向往，在天亮之前，心里有光。

## 关于这个网站

- 主要存放：学习笔记、读书感悟、日常随想
- 技术栈：[Astro](https://astro.build) + [Fuwari](https://github.com/saicaca/fuwari) 主题
- 内容以 Markdown 编写，持续更新中

## 联系我
